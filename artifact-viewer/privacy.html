プライバシーポリシー

makkopai（以下「運営者」）は、iOS、iPadOS、macOS 向けアプリ「Artifact Viewer」（以下「本アプリ」）での利用者の情報の扱いについて、次のとおり定めます。

制定日：2026 年 11 月 13 日

1. 基本的な考え方

本アプリは、AI サービスなどで作られた HTML ファイル（以下「アーティファクト」）を、利用者の端末で保存して表示するためのアプリです。

  • 本アプリは、アカウントの登録なしで使えます。
  • 利用者が取り込んだアーティファクトの中身、タイトル、ファイル名、アーティファクトが端末に保存したデータは、運営者のサーバーに送りません。 これらは利用者の端末の中に保存されます。iCloud 同期をオンにした場合は、利用者自身の iCloud にも保存されます（2 章）。
  • 運営者は、利用者の氏名、メールアドレス、電話番号、位置情報、連絡先、写真などを取得しません（お問い合わせのメールを除きます。11 章）。

2. 端末の中に保存される情報

本アプリは、機能を提供するために、次の情報を利用者の端末の中に保存します。これらの情報が運営者に送られることはありません。

情報内容
アーティファクト取り込んだ HTML ファイルのコピー
アーティファクトの情報タイトル、元のファイル名、追加日時、更新日時、お気に入り、フォルダの分類
サムネイルライブラリに表示するために、アーティファクトの表示を縮小した画像
ページ内のデータアーティファクトが保存するデータ（localStorage など）。ほかに、ブラウザと同じように、キャッシュや Cookie が保存される場合があります
表示の設定テーマ（ライト・ダーク）、配色、並べ替えの順、表示の形式など
分析と健康診断のための記録アーティファクトの特徴（推定した用途、分野、作った AI、使っているライブラリ、言語、大きさ）、開いた日と回数、表示していた時間、取り込み方、更新や削除の回数、健康診断の結果。「ライブラリの分析」と「健康診断」の画面に使います。ページの文章やタイトルは記録しません

iCloud 同期
設定で「iCloud で同期」をオンにすると、上の表のうち、アーティファクト、アーティファクトの情報、フォルダを、Apple の iCloud の利用者専用の領域（CloudKit の非公開データベース）に保存し、同じ Apple ID の端末の間で同期します。

  • 保存先は利用者の iCloud で、運営者はその中身を見ることができません。保存した分は利用者の iCloud の容量を使います。
  • サムネイル、ページ内のデータ、表示の設定、分析と健康診断のための記録は同期しません。
  • iCloud での情報の扱いは、Apple のプライバシーポリシーに従います。

削除の方法

  • アーティファクトをアプリの中で削除すると、そのアーティファクトのファイル、サムネイル、ページ内のデータを削除します。iCloud 同期をオンにしている場合は、iCloud と、同期しているほかの端末からも削除します。
  • 本アプリを端末から削除すると、その端末の中の情報はすべて削除されます。iCloud に保存した分は、端末の「設定」アプリの iCloud の管理画面から削除できます。

3. アーティファクト自体による外部との通信

アーティファクトは、作った人や AI サービスによって、外部のサーバーと通信するように作られている場合があります。たとえば次のような場合です。

  • スクリプトや画像、フォントを外部から読み込む（CDN や Google Fonts など）
  • 地図、動画などの外部のサービスを埋め込む
  • アーティファクトの中から外部の Web サービスにデータを送る

この場合、ブラウザで Web ページを見るときと同じように、利用者の IP アドレス、端末やブラウザの種類などが、その通信先に送られます。通信の有無と内容は、アーティファクトの中身によって決まります。運営者はこれを管理しておらず、その通信先での情報の扱いについて責任を負いません。 それぞれの通信先のプライバシーポリシーをご確認ください。

アーティファクトの中のリンクを開くと、本アプリではなく、端末の標準のブラウザ（Safari など）で開きます。

4. 運営者が取得する情報

運営者が取得する情報、または運営者が組み込んだ仕組みによって外部に送られる情報は、5 章（広告）と 6 章（利用統計）に書いたものだけです。

このほか、有料機能を購入した利用者が「みんなの傾向」を表示するとき、本アプリは、運営者が Google Cloud Storage に置いた集計済みの数字のファイルを読み込みます。この通信では、Web ページを読み込むときと同じように、IP アドレスなどの通信に必要な情報が Google LLC に送られます。運営者は、この通信の記録を利用者の分析に使いません。

5. 広告

本アプリは、Google LLC が提供する広告配信サービス「Google AdMob」を使って、iPhone と iPad で次の広告を表示します。Mac では広告を表示しません。有料機能を購入した利用者には広告を表示せず、AdMob も動かしません。

  • ライブラリの画面の下に表示する広告（バナー広告）
  • 保存できる件数を増やすために、利用者が見るかどうかを選んで見る広告（リワード広告）

アーティファクトを表示している画面には、広告を表示しません。

AdMob は、広告の配信、効果の測定、不正の防止のために、次のような情報を取得します。

  • 端末の広告識別子（IDFA）。iOS の「トラッキングの許可」で利用者が許可した場合に限ります
  • IP アドレス、端末の種類、OS のバージョン、言語の設定
  • 広告の表示やタップなどの操作の記録

本アプリは、初めて起動したときに、トラッキングを許可するかどうかを尋ねます。

  • 許可しない場合、利用者に合わせた広告（パーソナライズド広告）は表示されません。広告の表示自体は続きます。どちらを選んでも、本アプリの機能はすべて使えます
  • 端末の「設定」アプリで、トラッキングの許可をいつでも変更できます

Google での情報の扱いについては、Google のプライバシーポリシー と、Google のパートナーのサイトやアプリを使用する際の Google によるデータ使用 をご確認ください。

広告の仕組みが取得する情報と、6 章の利用統計を組み合わせることはありません。

6. 利用統計

本アプリは、利用者が同意した場合に限り、本アプリの改善と、統計の作成のために、利用統計を送ります。同意するかどうかは、アーティファクトを 3 件取り込んだとき、または「ライブラリの分析」を初めて開いたときに選べ、設定の画面からいつでも変更できます。送る内容は、同意の画面と設定の画面で確認できます。

利用統計の送信には、Google LLC が提供する「Google Analytics for Firebase」を使います。同意するまで、この仕組みは情報を集めません。

送る情報

  • アーティファクトの種類を、あらかじめ決めた選択肢に変えたもの（例：作った AI の推定、用途と分野の分類、言語、使われている技術やライブラリの種類、扱っているデータの種類、外部との通信の種類）
  • アーティファクトの規模を表す数（例：行数、関数や入力欄の数、文字数、ファイルの大きさ）。上 2 桁に丸めて送ります
  • アーティファクトごとに端末の中で作るランダムな識別子。アーティファクトの中身やファイル名からは作りません
  • 使われ方のおおまかな区分（例：1 週間に開いた回数と日数、表示時間、取り込んでからの日数、お気に入りやフォルダに入れているか、取り込み方、テーマの設定、削除したときの保存期間）
  • 健康診断で見つかった問題の種類（例：横にはみ出す、文字が小さい）
  • 「ひとこと質問」に答えた場合は、その答え（あらかじめ決めた選択肢から選んだもの）。ひとこと質問は設定の画面でオフにできます
  • 利用者の区分：有料機能を購入しているか、ライブラリの件数の区分、iCloud 同期のオンとオフ
  • Google Analytics for Firebase が自動で集める情報：アプリごとに割り当てられる識別子（アプリインスタンス ID）、端末の種類、OS とアプリのバージョン、言語の設定、おおよその地域（IP アドレスから推定）、起動や利用時間、アプリ内の購入、送信の日時

送らない情報

  • アーティファクトの中身、タイトル、ファイル名、URL、ページ内のデータ、ページの文章、エラーの文面
  • 広告識別子（IDFA）、ベンダー識別子（IDFV）、位置情報サービスによる位置情報
  • 外部との通信の送り先のアドレス（種類だけを送ります）

利用統計は、5 章の広告の情報と組み合わせず、広告のパーソナライズには使いません。

利用統計の送信をオフにすると、それ以降は送らず、端末の中のアプリインスタンス ID も消します。運営者は送られてきた情報から利用者を特定できないため、利用者ごとに探して消すことはできません。Google での情報の扱いについては、Google のプライバシーポリシー をご確認ください。

みんなの傾向
運営者は、送られてきた利用統計をまとめた数字（例：作った AI ごとの割合）を作り、本アプリの「ライブラリの分析」に表示します。この数字のファイルは誰でも取得できますが、利用者の数が少ない区分は含めません。

統計の第三者への提供
運営者は、多くの利用者のデータをまとめ、個人や端末を特定できない形にした統計を、第三者に提供したり、調査やレポートに使ったりすることがあります。利用者の数が少なく、特定につながるおそれがある区分は出しません。

送り先：Google LLC（Google Analytics for Firebase）。集めた情報は、運営者が管理する Google Cloud の BigQuery に書き出して集計します。

7. 有料機能の購入

有料機能の購入と支払いは、Apple の App Store を通じて行われます。運営者は、クレジットカードの情報などの支払いの情報を取得しません。

購入したかどうかの確認は、Apple の仕組み（StoreKit）を使って、利用者の端末の中で行います。

9. 子供の利用

本アプリは、子供向けに作られたものではありません。運営者は、子供の個人情報を意図して取得することはありません。

10. 第三者への提供

運営者は、法令に基づく場合を除き、利用者の個人情報を第三者に提供しません。6 章の統計は、個人を特定できない形にしたものです。
